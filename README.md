# Agaia

Quiero que crees una landing page moderna, visual, sobria y contemporánea para una marca enfocada en bienestar, naturaleza, salud, calma, energía y sensaciones naturales.

La marca trabaja con elementos naturales, ingredientes limpios y una filosofía relacionada con el bienestar integral, la calma, la conexión con la naturaleza y el equilibrio. La página debe sentirse elegante, serena, visualmente atractiva y fácilmente reconocible tanto para web como para futuras aplicaciones en empaques, redes sociales y piezas comerciales.

Voy a adjuntar los logos de la marca. Usa los logos como referencia principal de identidad visual y aplícalos de forma estratégica en la landing: header, hero section, footer y, si aplica, elementos decorativos sutiles. No deformes el logo ni cambies su proporción.

Paleta de colores:

- Color principal: azul profundo #295275

  RGB: 41, 82, 117

  CMYK: 90, 67, 33, 16

- Color secundario: azul claro #BBE0EF

  RGB: 187, 224, 239

  CMYK: 25, 2, 3, 0

El azul principal debe transmitir alma, bienestar, profundidad, confianza y calma. El azul claro debe usarse como color de apoyo para fondos suaves, secciones respirables, tarjetas, detalles visuales y sensación de frescura.

Tipografías:

- Tipografía principal: Powell

- Tipografía secundaria: Citrine

Usa Powell para títulos principales, frases de impacto, elementos de marca y encabezados importantes. Usa Citrine para subtítulos, textos descriptivos, botones y contenido secundario. Si las fuentes no están disponibles directamente, deja la estructura preparada para importarlas posteriormente y usa fuentes fallback elegantes, limpias y contemporáneas.

Estilo visual general:

- Diseño minimalista, sobrio y premium.

- Mucho espacio en blanco/aire visual.

- Secciones limpias, con bordes suaves y detalles orgánicos.

- Estética relacionada con bienestar, calma, naturaleza, energía suave y salud.

- Evitar saturación visual o colores demasiado fuertes.

- Usar formas suaves, líneas fluidas, ondas, degradados sutiles o elementos inspirados en agua, aire, hojas, minerales o energía natural.

- Debe sentirse moderna, confiable y muy visual.

- Debe ser responsive: perfecta en celular, tablet y computador.

Estructura sugerida de la landing:

1. Header / navegación

Crear un header limpio con el logo, menú de navegación y un botón CTA.

Menú sugerido:

- Inicio

- Productos

- Bienestar

- Ingredientes

- Nosotros

- Contacto

CTA sugerido:

“Conoce nuestros productos” o “Conecta con nosotros”

2. Hero section

Crear una primera sección muy visual, elegante y emocional.

Debe incluir:

- Logo o isotipo de forma destacada pero sobria.

- Frase principal potente, relacionada con bienestar natural, calma y conexión.

Ejemplo de copy:

“Bienestar natural para reconectar con tu esencia”

o

“Elementos naturales para cuidar tu cuerpo, tu energía y tu calma”

- Texto corto de apoyo:

“Creamos productos inspirados en la naturaleza, los ingredientes limpios y las sensaciones que acompañan una vida más consciente.”

- Botones:

“Explorar productos”

“Conocer la marca”

- Espacio para imagen principal, mockup de producto, textura natural, foto lifestyle o composición visual con los logos adjuntos.

3. Sección de propuesta de valor

Crear una sección que explique claramente qué hace diferente a la marca.

Usar tarjetas visuales con íconos o elementos gráficos.

Ideas de tarjetas:

- Ingredientes naturales

- Bienestar y calma

- Diseño simple y consciente

- Inspirado en la naturaleza

- Experiencias sensoriales

- Energía y equilibrio

No hacer promesas médicas ni afirmar que los productos curan enfermedades. El lenguaje debe enfocarse en bienestar, sensación, rutina, cuidado personal y experiencia natural.

4. Sección de productos

Crear una sección de productos muy vistosa, con tarjetas elegantes.

Debe permitir mostrar categorías o productos individuales.

Cada tarjeta debe incluir:

- Imagen o placeholder de producto

- Nombre del producto

- Descripción corta

- Ingredientes o elementos destacados

- Sensación asociada, por ejemplo: calma, frescura, energía, equilibrio, descanso

- Botón “Ver más” o “Consultar disponibilidad”

Si todavía no hay productos definidos, crear una estructura flexible con productos placeholder como:

- Línea Calma

- Línea Energía

- Línea Equilibrio

- Línea Naturaleza

5. Sección informativa: ingredientes y naturaleza

Crear una sección que explique el enfoque en ingredientes naturales.

Debe tener un diseño visual, con bloques de información, imágenes suaves y texto claro.

Copy sugerido:

“Cada elemento nace de una selección consciente de ingredientes naturales, pensados para acompañar rituales de bienestar, autocuidado y conexión con lo esencial.”

Incluir espacio para listar ingredientes, beneficios sensoriales y origen natural.

6. Sección de experiencia / ritual

Crear una sección que muestre cómo se integran los productos en una rutina de bienestar.

Ejemplo:

- Respira

- Aplica / usa

- Conecta

- Siente

Esta sección debe ser muy visual y emocional, mostrando que la marca no vende solo productos, sino experiencias de calma y bienestar.

7. Sección “Sobre la marca”

Crear una sección para contar la historia y filosofía de la marca.

Debe hablar de:

- Amor por la naturaleza

- Cuidado consciente

- Bienestar simple y cotidiano

- Diseño sobrio y reconocible

- Conexión entre cuerpo, mente, energía y entorno

Copy sugerido:

“Nacimos con la intención de crear elementos simples, naturales y visualmente honestos, capaces de acompañar momentos de calma, presencia y bienestar.”

8. Sección de redes sociales / comunidad

Crear una sección para conectar Instagram, TikTok, WhatsApp, Facebook o las redes que se definan.

Debe tener botones visibles y elegantes.

Incluir espacio para:

- Galería de Instagram

- Fotos de productos

- Contenido lifestyle

- Testimonios o frases de clientes

CTA sugerido:

“Síguenos y descubre rituales de bienestar natural”

9. Sección de contacto

Crear una sección clara para contacto comercial y general.

Debe incluir:

- Formulario de contacto

- Nombre

- Correo

- Teléfono

- Mensaje

- Motivo de contacto: comprar, distribución, colaboración, información general

- Botón para WhatsApp

- Botón para redes sociales

Copy sugerido:

“¿Quieres conocer más sobre nuestros productos o trabajar con nosotros? Escríbenos y conectemos.”

10. FAQ / preguntas frecuentes

Crear una sección de preguntas frecuentes.

Preguntas sugeridas:

- ¿Los productos son naturales?

- ¿Dónde puedo comprarlos?

- ¿Hacen envíos?

- ¿Puedo venderlos en mi tienda?

- ¿Cómo se usan los productos?

- ¿Los productos tienen contraindicaciones?

- ¿Cómo puedo contactar a la marca?

11. Footer

Crear un footer sobrio con:

- Logo

- Frase corta de marca

- Links principales

- Redes sociales

- Contacto

- Derechos reservados

Requisitos técnicos y de diseño:

- La página debe ser totalmente responsive.

- Debe cargar rápido.

- Debe tener buena jerarquía visual.

- Usar animaciones suaves, no exageradas.

- Botones con hover elegante.

- Tarjetas con sombras muy sutiles.

- Usar el azul #295275 como color dominante y #BBE0EF como color secundario.

- Mantener un estilo premium, natural, sereno y contemporáneo.

- Preparar la estructura para que después se puedan cambiar textos, imágenes, productos y enlaces fácilmente.

- Optimizar la página para conversión: debe invitar a explorar productos, contactar y seguir redes sociales.

- Incluir placeholders claros para imágenes de productos, fotos lifestyle, logos y enlaces de redes.

Objetivo final:

Crear una landing page que transmita bienestar, naturaleza, calma, confianza y estética premium. Debe servir como carta de presentación de la marca, mostrar sus productos, explicar su filosofía, conectar con redes sociales y facilitar el contacto de clientes, distribuidores o aliados comerciales.
